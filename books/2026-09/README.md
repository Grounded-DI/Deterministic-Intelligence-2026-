## Download the complete original ZIP

Download [download_collection.py](download_collection.py) using GitHub's **Download raw file** button, then run:

```sh
python3 download_collection.py
```

The script downloads nine archive parts, assembles them in order, and verifies the original SHA-256 before writing `Grounded_DI_Book_Collection_2026-09_Revised.zip`. It uses only Python's standard library. Extract that ZIP to access all nine books in their original four subject folders.

If you downloaded this entire repository, run the same script from its saved location; it will use the adjacent local `archive/` parts.

The parts exist because the publication connector limits request size. They are pieces of one original ZIP, not separate ZIP files; do not unzip them individually.
